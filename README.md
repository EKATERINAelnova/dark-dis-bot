# 🌒 LOST EDEN · Discord Bot

> **We don't return. We rebuild.**

Discord-бот для сервера **LOST EDEN · RIMAY**, написанный на Python с использованием `discord.py`.

Проект развивается как собственный бот сервера: без лишнего универсального функционала, с единым визуальным стилем, интерактивными интерфейсами и механиками, связанными со структурой LOST EDEN.

---

## About

**LOST EDEN Bot** создаётся специально для Discord-сервера **LOST EDEN · RIMAY**.

Это не универсальный бот-комбайн с десятками случайных команд. Проект строится вокруг конкретных задач сервера и постепенно становится частью его интерфейса.

Основные принципы:

* только действительно нужный функционал;
* slash-команды через Discord Application Commands;
* интерактивные интерфейсы на `discord.ui`;
* единое оформление embed-сообщений;
* разделение функционала по модулям;
* простая и расширяемая архитектура;
* визуальная интеграция с концепцией **Lost Eden / Paradise**.

Главная идея проекта:

> **We don't return. We rebuild.**

Бот выступает проводником по LOST EDEN: помогает ориентироваться на сервере, получать информацию и взаимодействовать с его механиками.

## 🗂️ Навигация по репозиторию

Основной код бота разделён по назначению, чтобы отдельные механики не смешивались друг с другом.

```text
dark-dis-bot/
│
├── bot/
│   ├── cogs/
│   │   ├── general/
│   │   └── fun/
│   │
│   ├── views/
│   ├── theme/
│   └── ...
│
├── main.py
├── requirements.txt
├── .gitignore
└── README.md
```

### `main.py`

Точка входа в приложение.

Отвечает за запуск Discord-клиента, загрузку компонентов бота и подключение к Discord API.

---

### `general`

Основные информационные и серверные команды.

Здесь располагается функционал, связанный с:

* информацией о сервере;
* информацией о пользователях;
* навигацией;
* системными командами.

---

### `fun`

Независимые развлекательные команды.

Сюда вынесены небольшие игровые механики, которые не относятся к основному интерфейсу сервера.

---

### `views`

Интерактивные Discord-интерфейсы на основе `discord.ui.View`.

Используются для:

* кнопок;
* переключения страниц;
* интерактивных меню;
* мини-игр.

---

### `theme`

Единая система оформления embed-сообщений.

Она позволяет централизованно управлять:

* цветами;
* заголовками;
* footer;
* декоративными элементами;
* стилем информационных карточек.

Благодаря этому интерфейс бота сохраняет единый визуальный язык LOST EDEN.

# ✅ Реализованные команды

## `/serverinfo`

Главная информационная команда сервера.

```text
/serverinfo
```

Открывает интерактивную карточку **LOST EDEN · RIMAY**.

Вместо одного большого embed команда использует несколько связанных страниц.

### Главная страница

Содержит основную информацию о сервере и является центральной точкой интерфейса.

Из неё доступны переходы к другим разделам.

```text
LOST EDEN
│
├── Rules
└── Navigation
```

Переключение происходит через Discord-кнопки без создания новых сообщений.

---

### Rules

Страница с правилами сервера.

Позволяет просматривать правила непосредственно через интерфейс `/serverinfo`.

После перехода пользователь может вернуться на главную страницу.

---

### Navigation

Страница навигации по серверу.

Объясняет структуру LOST EDEN и помогает понять назначение основных разделов и каналов.

---

### Интерактивный интерфейс

Для переключения страниц используются:

```python
discord.ui.View
discord.ui.Button
```

Сообщение редактируется после нажатия кнопки, поэтому меню остаётся компактным и не засоряет канал дополнительными embed.

---

## `/userinfo`

```text
/userinfo @user
```

Показывает информацию об участнике Discord-сервера.

Карточка содержит:

* имя пользователя;
* отображаемое имя;
* Discord ID;
* дату создания аккаунта;
* список ролей;
* аватар.

Команда использует единое оформление embed LOST EDEN.

---

## `/ping`

```text
/ping
```

Небольшая системная команда для проверки работы Discord-бота.

Позволяет быстро убедиться, что бот запущен и отвечает на interactions.

---

## `/roll`

```text
/roll max_value
```

Генерирует случайное число.

Например:

```text
/roll 100
```

может вернуть:

```text
67
```

Максимальное значение ограничено диапазоном:

```text
1–1000
```

---

## `/coin`

```text
/coin
```

Интерактивная мини-игра с выбором стороны монеты.

После запуска пользователь получает две кнопки:

```text
Орёл
Решка
```

После выбора бот:

1. случайным образом определяет сторону монеты;
2. сравнивает результат с выбором пользователя;
3. показывает результат;
4. блокирует дальнейшее использование кнопок.

Интерфейс реализован через:

```python
discord.ui.View
discord.ui.Button
```

# 🌱 Планируется

Проект развивается постепенно. Новые функции добавляются только тогда, когда они действительно нужны серверу.

## Onboarding

Система знакомства новых участников с LOST EDEN.

Планируется объединить:

```text
Welcome
   │
   ├── About
   ├── Rules
   ├── Navigation
   └── Roles
```

в единый понятный интерактивный путь.

---

## Role selection

Интерактивный выбор ролей через Discord-компоненты.

Вместо обычного сообщения с реакциями бот сможет использовать кнопки или select-меню.

Роли постепенно могут стать не просто техническими группами доступа, а частью структуры LOST EDEN.

---

## Более развитая навигация

Развитие `/serverinfo` до полноценного интерфейса сервера.

Возможные разделы:

```text
LOST EDEN
│
├── About
├── Rules
├── Navigation
├── Roles
├── Events
└── Help
```

---

## Welcome system

Автоматическое приветствие новых участников.

Welcome-система должна не просто сообщать:

```text

```

а помогать человеку понять, куда он попал и что делать дальше.
