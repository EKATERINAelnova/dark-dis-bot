# 🌒 LOST EDEN · Discord Bot

> **We don't return. We rebuild.**

Discord-бот для сервера **LOST EDEN · RIMAY**, написанный на Python с использованием `discord.py`.

Проект развивается как собственный бот сервера: без лишнего универсального функционала, с единым визуальным стилем, интерактивными интерфейсами, системой профилей и механиками, связанными со структурой LOST EDEN.

---

## About

**LOST EDEN Bot** создаётся специально для Discord-сервера **LOST EDEN · RIMAY**.

Это не универсальный бот-комбайн с десятками случайных команд. Проект строится вокруг конкретных задач сервера и постепенно становится частью его интерфейса и внутренней инфраструктуры.

Основные принципы:

* только действительно нужный функционал;
* slash-команды через Discord Application Commands;
* интерактивные интерфейсы на `discord.ui`;
* единое оформление embed-сообщений;
* собственные графические карточки через Pillow;
* разделение функционала по модулям;
* постоянное хранение пользовательской статистики;
* простая и расширяемая архитектура;
* визуальная интеграция с концепцией **Lost Eden / Paradise**.

Главная идея проекта:

> **We don't return. We rebuild.**

Бот выступает проводником по LOST EDEN: помогает ориентироваться на сервере, хранит статистику активности участников, формирует профили и постепенно становится частью жизни самого сада.

### `general`

Основной пользовательский интерфейс бота.

Содержит команды:

```text
/ping
/profile
/userinfo
/serverinfo
/testbanner
```

Здесь располагается функционал, связанный с:

* профилями участников;
* информацией о сервере;
* информацией о пользователях;
* навигацией;

### `fun`

Независимые развлекательные механики.

Сейчас содержит:

```text
/roll
/coin
```

Игровой интерфейс монетки вынесен отдельно в `views/coin_view.py`.

---

### `activity.py`

Система сбора активности участников.

Автоматически отслеживает:

* количество отправленных сообщений;
* время, проведённое в голосовых каналах.

Боты и личные сообщения не учитываются.

Данные записываются в SQLite и используются профилем участника.

---

### `server_stats.py`

Фоновая статистика сервера.

Бот поддерживает отдельное сообщение со значениями:

```text
В сети: ...
Участников: ...
```

Статистика периодически проверяется и сообщение редактируется только при изменении значений.

Если сообщение было удалено вручную, бот создаёт новое.

Канал задаётся через:

```env
STATS_CHANNEL_ID=...
```

---

### `welcome/banner.py`

Система динамического баннера LOST EDEN.

Бот отслеживает:

* количество участников онлайн;
* общее количество участников.

Когда значения меняются, генерируется новый баннер с актуальной статистикой:

```text
12 В САДУ
47 ДУШ
```

Баннер создаётся через Pillow поверх подготовленного шаблона LOST EDEN.

Обновление выполняется только если сервер поддерживает баннеры и бот имеет необходимые права.

### `database`

Слой постоянного хранения данных.

Используется SQLite-база:

```text
data/eden.db
```

Основная таблица:

```text
member_stats
```

Сейчас для каждого участника хранятся:

```text
guild_id
user_id
messages
voice_seconds
currency
```

Участник определяется парой:

```text
guild_id + user_id
```

поэтому статистика может независимо существовать для разных серверов.

---

### `utils/profile_card.py`

Генератор графической карточки профиля.

Карточка создаётся через Pillow на основе подготовленного шаблона LOST EDEN.

На неё наносятся:

* аватар;
* отображаемое имя;
* Discord username;
* роли;
* уровень;
* место в рейтинге;
* EXP;
* EXP до следующего уровня;
* баланс;
* количество сообщений;
* время в голосовых каналах.

Сейчас реальные значения уже используются для:

```text
messages
voice time
currency
```

Поля:

```text
level
rank
EXP
EXP to next level
```

пока используют тестовые значения и будут подключены к системе уровней на следующем этапе.

---

### `utils/server_banner.py`

Генератор динамического серверного баннера.

Использует:

```text

```

как основу и добавляет актуальные данные сервера поверх изображения.

# ✅ Реализованные команды

## `/profile`

```text
/profile
```

или:

```text
/profile @user
```

Открывает полноценную графическую карточку участника LOST EDEN.

Если пользователь не указан, показывается профиль автора команды.

Карточка содержит:

```text
Аватар
Имя
Discord username
Роли
Уровень
Рейтинг
EXP
Баланс
Сообщения
Voice time
```

Информация о сообщениях, голосовой активности и балансе уже загружается из SQLite.

Уровень, рейтинг и EXP пока являются подготовленной частью интерфейса и будут подключены к реальным расчётам после реализации leveling-системы.

## `/serverinfo`

```text
/serverinfo
```

Открывает интерактивную карту **LOST EDEN · RIMAY**.

Интерфейс состоит из нескольких страниц:

```text
LOST EDEN
│
├── 🌳 О саде
├── 📜 Правила
└── 🧭 Навигация
```

Переключение происходит внутри одного Discord-сообщения.

---

### 🌳 О саде

Главная страница отображает:

* количество участников;
* хранителя сервера;
* дату создания;
* количество текстовых каналов;
* количество голосовых каналов;
* количество ролей;

### 📜 Правила

---

### 🧭 Навигация

Интерактивная карта каналов сервера.

Каналы группируются по пространствам:

```text
🍃 Вход в сад
```

```text

```

## `/roll`

```text
/roll max_value
```

Генерирует случайное число от `1` до указанного максимума.

Например:

```text
/roll 100
```

может вернуть:

```text
67
```

Допустимый диапазон:

```text

```

---

## `/coin`

```text
/coin
```

Интерактивная мини-игра с выбором стороны монеты.

После запуска пользователь получает:

```text
[ Орёл ] [ Решка ]
```

После выбора бот:

1. случайным образом определяет результат;
2. сравнивает его с выбором игрока;
3. сообщает о победе или поражении;
4. отключает обе кнопки.

Нажимать кнопки может только пользователь, который запустил игру.

Попытка взаимодействовать с чужой игрой получает отдельный ephemeral-ответ.

---

## `/testbanner`

```text
/testbanner
```

Служебная команда для тестирования генерации динамического баннера.

Команда:

* считает участников онлайн;
* считает общее количество участников;
* генерирует изображение;
* устанавливает новый баннер сервера.

Используется в процессе разработки и в дальнейшем может быть удалена или ограничена только администраторами.

# ✅ Реализованные фоновые механики

## Activity tracking

Бот автоматически собирает статистику активности.

### Сообщения

Каждое сообщение участника увеличивает:

```text
messages
```

Боты и сообщения вне сервера не учитываются.

### Голосовые каналы

При входе участника в voice бот запоминает время начала сессии.

После выхода рассчитывается длительность и добавляется к:

```text
voice_seconds
```

Перемещения между голосовыми каналами не должны создавать новую независимую статистику активности.

---

## SQLite storage

Пользовательская статистика уже сохраняется постоянно.

При перезапуске процесса данные:

```text
messages
voice_seconds
currency
```

не теряются.

Это создаёт основу для:

* EXP;
* уровней;
* рейтингов;
* экономики;
* достижений;
* будущих Garden mechanics.

---

## Dynamic server banner

Бот автоматически поддерживает баннер сервера с актуальной статистикой LOST EDEN.

На изображении отображается:

```text
N В САДУ
N ДУШ
```

Новый баннер генерируется только после изменения количества участников или пользователей онлайн.

---

## Live server statistics

Бот поддерживает отдельное сообщение со статистикой:

```text
В сети
Участников
```

Вместо постоянной отправки новых сообщений редактируется уже существующее.

## EXP & Leveling

Следующий основной этап разработки.

Уровень участника будет зависеть от его реального участия в жизни сада:

```text
Messages ─┐
          ├──→ EXP ──→ Level
Voice ────┘
```

Планируется:

* начисление EXP за активность в текстовых каналах;
* начисление EXP за время в voice;
* защита от фарма EXP через спам;
* вычисление уровня из общего EXP;
* EXP до следующего уровня;
* серверный рейтинг;
* подключение реальных значений к `/profile`.

После реализации тестовые:

```text
LEVEL
RANK
EXP
NEXT LEVEL
```

в карточке профиля будут полностью заменены данными из базы.
