# 🌒 LOST EDEN · Discord Bot

> **We don't return. We rebuild.**

Discord-бот для сервера **LOST EDEN · RIMAY**.

Это не универсальный бот-комбайн с сотней случайных команд. Он создаётся как часть самого сервера: его атмосферы, структуры, ролей и внутренней мифологии.

**LOST EDEN** строится вокруг образа утраченного сада. Мы не пытаемся вернуться в прежний рай. Мы создаём новый.

Бот становится одним из инструментов этого восстановления.

---

## 🕯️ Концепция

В основе проекта лежит образ **Lost Eden / Paradise Lost**:

* утраченный рай;
* запретный плод и знание;
* свобода воли;
* изгнание;
* поиск собственного места;
* распад старого сообщества;
* создание нового сада.

Отсюда главный принцип проекта:

> **We don't return. We rebuild.**

Бот не должен ощущаться как безликий `/help`, `/ban`, `/rank`-автомат.

Его интерфейс, сообщения, роли и механики постепенно адаптируются под эстетику **LOST EDEN**.

## 🌿 Что умеет бот

Сейчас реализована базовая система Discord-команд.

### `/ping`

Проверяет, жив ли бот.

```text
/ping
→ Pong!
```

---

### `/userinfo`

Показывает информацию об участнике сервера:

* имя;
* отображаемое имя;
* Discord ID;
* дату регистрации аккаунта;
* роли;
* аватар пользователя.

Пример:

```text
/userinfo @user
```

---

### `/serverinfo`

Информация о текущем Discord-сервере.

Планируется постепенно превратить эту команду из обычной статистики в полноценную **карту сада**.

---

### `/roll`

Бросок случайного числа.

```text
/roll 100
```

Например:

```text
67
```

Поддерживается диапазон:

```text
1–1000
```

---

### `/coin`

Мини-игра с интерактивными Discord-кнопками.

Игрок выбирает:

```text
Орёл
Решка
```

После выбора бот случайно определяет результат.

Используются `discord.ui.View` и интерактивные `Button`.

---

## 🌘 Куда развивается проект

Текущие команды являются фундаментом.

Главная цель проекта состоит в том, чтобы бот постепенно стал **внутренней системой LOST EDEN**, а не просто набором slash-команд.

Планируемые направления:

### 🌱 The Garden

Система состояния сообщества.

Бот сможет отражать развитие сервера как развитие сада:

```text
seed → root → bloom → ruin → rebirth
```

Активность участников может влиять на состояние отдельных частей мира.

---

### 🜏 Роли как состояния

Роли сервера могут перестать быть просто:

```text
Member
Moderator
Admin
```

и стать частью мира LOST EDEN.

Например:

```text
The Exiled
The Rooted
The Witness
The Keeper
The Fallen
The Architect
```

Роль может отражать не только права пользователя, но и его место внутри сада.

---

### 🍎 Forbidden Fruit

Система редких событий, загадок или скрытых взаимодействий.

Некоторые команды могут:

* появляться только при определённых условиях;
* открываться после событий;
* содержать скрытые ответы;
* менять состояние пользователя;
* давать доступ к новым областям сервера.

---

### 📜 Chronicle

История сервера.

В будущем бот сможет хранить важные события:

```text
кто пришёл
что произошло
какие события изменили сервер
какие эпохи пережил сад
```

Получится своеобразная цифровая летопись сообщества.

---

### 🕯️ Rituals

События, запускаемые ботом:

* голосования;
* выборы;
* временные роли;
* игровые события;
* коллективные решения;
* сезонные изменения сервера.

---

### 🪦 Memory

Одна из центральных тем LOST EDEN — память об утраченном.

Бот может сохранять:

* старые названия каналов;
* завершённые события;
* исчезнувшие роли;
* памятные сообщения;
* этапы развития сообщества.

То, что исчезло, не обязательно должно быть забыто.

## 📦 Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/EKATERINAelnova/dark-dis-bot.git
```

Перейдите в директорию проекта:

```bash
cd dark-dis-bot
```

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его.

### Windows

```bash
.venv\Scripts\activate
```

### Linux / macOS

```bash
source .venv/bin/activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

---

## 🔑 Настройка Discord-токена

Создайте в корне проекта файл:

```text
.env
```

Добавьте:

```env
DIS_TOKEN=YOUR_DISCORD_BOT_TOKEN
```

Токен необходимо получить через **Discord Developer Portal**.

> Никогда не добавляйте `.env` в Git.

В `.gitignore` рекомендуется иметь:

```gitignore
.env
.venv/
__pycache__/
*.pyc
```

## 🧩 Slash Commands

Проект использует современную систему Discord Application Commands.

Команды синхронизируются через:

```python
discord.app_commands.CommandTree
```

Для разработки может использоваться синхронизация команд с конкретным Discord-сервером.

Это позволяет обновлять команды почти мгновенно, не ожидая глобальной синхронизации Discord.

## 🛡️ Принципы проекта

### 1. Никакого bot-bloat

Если функция не нужна серверу, она не добавляется.

---

### 2. Атмосфера важна

Даже техническая функция может быть оформлена как часть мира LOST EDEN.

Не:

```text
Your level is 7.
```

А потенциально:

```text
Your roots reached deeper.

Depth: VII
```

---

### 3. Механики должны иметь смысл

Геймификация ради цифр быстро превращается в шум.

Каждая крупная механика должна отвечать на вопрос:

> Что она добавляет сообществу?

---

### 4. Бот поддерживает людей, а не заменяет их

Модерация, события и социальные механики должны усиливать человеческое взаимодействие.

---

### 5. Сервер меняется

LOST EDEN не предполагается статичным.

Структура каналов, визуальный язык, роли и механики могут эволюционировать вместе с сообществом.
